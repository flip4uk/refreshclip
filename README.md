# 🎬 RefreshClip

Telegram-бот [@RefreshClipBot](https://t.me/RefreshClipBot) — готовит видео к публикации на **YouTube**, **Instagram** и **TikTok**:
создаёт новую версию файла (кадр, цвет, скорость, звук, зерно, метаданные).

> ⚠️ Используйте бот только для своих материалов или тех, на которые у вас есть права.
> Платформы сами решают, как оценивать контент, — результат не гарантирован.

## ✨ Возможности

- 🎨 Цвет · ✂️ кадр · ⏩ скорость · 🔊 звук · 🎞 зерно · 🪞 зеркало · 🧹 очистка метаданных (всегда)
- 🌿 / ⚖️ / 🔥 — три уровня силы изменений
- 🔢 До 3 копий за раз — у каждой свои случайные параметры
- 📁 Отправка файлом (без пересжатия Telegram)
- 📊 Прогресс-бар обработки в реальном времени
- 🔐 Обязательная подписка на [@ads_247_ru](https://t.me/ads_247_ru)
- ⭐ Добровольные донаты в Telegram Stars (готовые суммы и своя)

## 🚀 Запуск на bothost.ru

1. **Токен.** В [@BotFather](https://t.me/BotFather) создайте бота с username `RefreshClipBot` и скопируйте токен.
   Никогда не публикуйте токен в репозитории.
2. **Репозиторий.** Создайте **новый** репозиторий на GitHub (например, `refreshclip-bot`) и загрузите в его корень 4 файла выше.
3. **Администратор канала.** Добавьте `@RefreshClipBot` в администраторы канала `@ads_247_ru`
   (достаточно минимальных прав) — иначе проверка подписки не сработает.
4. **Bothost.** Создайте новый проект, подключите репозиторий, добавьте переменную `BOT_TOKEN`, запустите деплой.
   Бот работает через long polling — открытые порты не нужны.

### Тариф bothost.ru

Обработка видео нагружает процессор и память. По данным с главной страницы bothost.ru:

| Тариф | Ботов | CPU | RAM |
|---|---|---|---|
| Starter (0 ₽) | 1 | 1 vCPU | 256 МБ |
| Basic (99 ₽/мес) | 5 | 2 vCPU | 1 ГБ |
| Pro (250 ₽/мес) | 20 | 4 vCPU | 2 ГБ |

- Если первый бот уже занимает единственный слот Starter, для второго нужен тариф **Basic** или выше.
- На 256 МБ видео в Full HD может не поместиться в память. Если бот «падает» во время обработки, задайте
  `VIDEO_MAX_SIDE=1280` и `FFMPEG_THREADS=1`.

## ⚙️ Переменные окружения

| Переменная | Обязательна | По умолчанию | Описание |
|---|---|---|---|
| `BOT_TOKEN` | ✅ | — | Токен бота |
| `CHANNEL_USERNAME` | — | `@ads_247_ru` | Канал для обязательной подписки |
| `BOT_USERNAME` | — | `RefreshClipBot` | Username бота (подпись под видео) |
| `ADMIN_CONTACT` | — | `@ads_247_ru` | Контакт для `/paysupport` |
| `MAX_DURATION` | — | `300` | Макс. длительность видео, сек. |
| `MAX_PARALLEL` | — | `1` | Сколько видео обрабатывать одновременно |
| `VIDEO_MAX_SIDE` | — | `1920` | Макс. длинная сторона кадра, px |
| `FFMPEG_THREADS` | — | `2` | Потоки ffmpeg |
| `FFMPEG_TIMEOUT` | — | `900` | Лимит времени на одну копию, сек. |

## 📏 Ограничения Telegram

- Бот может **принимать файлы только до 20 МБ** и отправлять до 50 МБ — это ограничение стандартного Bot API.
  Для файлов больше нужен собственный [Local Bot API Server](https://core.telegram.org/bots/api#using-a-local-bot-api-server).
- Если результат больше 50 МБ, бот автоматически пересоберёт его с большим сжатием.
